🚀 DeliveryX API Documentation

Complete API reference for all DeliveryX microservices

📝 Quick Start

Base URL (Traefik): http://localhost/api/v1

Direct Service Access:

  • Restaurant Service: http://localhost:8081/api/v1
  • Menu Service: http://localhost:8082/api/v1 (includes approval endpoints)
  • Media Service: http://localhost:8084/api/v1/media
